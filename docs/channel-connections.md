# Подключение VK, Telegram и MAX

## Сценарии пользователя

В разделе «Каналы» или настройках завода пользователь выбирает бренд и площадку.

- VK — «Подключить VK», разрешение в VK ID, выбор своего сообщества, подтверждение. Проверяется право загружать фото на стену. При отказе VK канал не сохраняется как готовый к публикации с фотографиями.
- Telegram — «Подключить Telegram», запуск общего бота, кнопка «Выбрать канал». Telegram предлагает назначить бота администратором. После возврата на сайт пользователь подтверждает подключение. Сервис проверяет права пользователя и право бота публиковать.
- MAX — «Подключить MAX», «Продолжить в MAX», запуск общего бота. Ссылка автоматически связывает аккаунт MAX с запросом на сайте. Бота надо добавить администратором канала, затем выбрать канал на сайте. Ручной код остаётся запасным вариантом.

Подключение из завода автоматически добавляет канал в этот завод. Бренд проверяется сервером. Повторное подтверждение не создаёт второй канал. Ручные подключения своими ключами остаются доступны.

## Настройка сервера

Применить `db/038_channel_connections.sql` штатным мигратором. Полная схема Adminer также обновлена. Незавершённые подключения действуют 15 минут, запросы MAX — 30 минут. PKCE и временные токены VK зашифрованы. Токен общего бота Telegram хранится только в окружении сервера.

### VK

- `APP_URL=https://juicerai.ru`
- `VK_CLIENT_ID=54812872` (или действительный ID приложения JuicerAI)
- `VK_SERVICE_TOKEN` — сервисный ключ для чтения публичных постов без подключения аккаунта.
- В доверенных Redirect URL используется `https://juicerai.ru/api/oauth/vk/callback` для входа и подключения каналов. Сценарии разделяются одноразовым state и отдельной серверной записью с PKCE.
- В кабинете VK получить доступы «Сообщества», «Стена» и «Фотографии». Обычный вход через VK ID не гарантирует доступ к методам VK API. Если права не доступны в кабинете, требуется обращение в поддержку VK с описанием сервиса автопубликации.

Для подключения используется Authorization Code + PKCE. Выдаются отдельные разрешения каждого пользователя. Сервисный и защищённый ключи приложения сами по себе не дают права публиковать в чужих сообществах. Подключённые токены VK обновляются на сервере через refresh token; отозванный доступ требует повторного подключения.

### Telegram

Создать общего бота сервиса через BotFather и задать:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_BOT_USERNAME` — имя без @
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка из латиницы, цифр, `_` и `-`, 16–256 символов.

В админке нажать «Подключить вебхук бота Telegram». Вебхук `https://juicerai.ru/api/telegram/webhook` проверяет секрет в `X-Telegram-Bot-Api-Secret-Token`. Эта кнопка настраивает единственный вебхук выбранного бота. Нужен отдельный бот JuicerAI, не бот другой системы.

Бот использует стандартную Telegram-кнопку request_chat для выбора канала. Вход на сайт через Telegram не заменяет разрешения на управление каналом.

### MAX

Существующие `MAX_BOT_TOKEN`, `MAX_BOT_USERNAME`, `MAX_WEBHOOK_SECRET`, `APP_URL` и вебхук `/api/max/webhook` сохраняются. Подписка должна включать `bot_started`, `bot_added`, `message_created`, `bot_admin_permissions_changed`. В админке есть кнопка подписки MAX.
