# Студия создания материалов

Экран `/app/create` использует двухколоночную компоновку из предоставленных макетов. На телефоне настройки располагаются под полем запроса. Правая панель прокручивается независимо на невысоких экранах.

- Основные форматы: пост, SEO-статья, карусель, сценарий ролика и инфографика. Остальные доступны в «Ещё».
- У карусели доступны модель изображений, количество слайдов, качество, пропорции, способ нанесения текста, логотип и его положение, визуальный стиль.
- Для остальных форматов — свои требования: SEO-запросы/объём, хронометраж и съёмка, экраны сторис, варианты опроса, исходные данные инфографики, цель письма, разделы гайда, правила конкурса.
- Подача, манера письма, аудитория, референсы и пресеты сохранены. Требования к формату передаются отдельно от референсов, чтобы модель использовала указанные числа и условия.
- Выбор текстовой модели применяется к описанию/плану и непосредственному созданию. AsyncLocalStorage изолирует выбор между запросами, не изменяя общие маршруты. Медиа- и vision-вызовы используют собственные модели.
- Сервер разрешает только текстовые модели, назначенные администратором маршрутам default/post/article/reels/carousel/plan/assistant. Список строится из БД, без сетевого запроса к каталогу шлюза при загрузке страницы. Автоматический режим сохраняет модель соответствующей задачи.
- Модели изображений и их цены берутся из существующего клиентского каталога администратора. Текстовые материалы сохраняют действующую фиксированную цену формата. Перед платной генерацией требуется подтверждение.

Проверки: общий набор тестов, отдельная проверка разрешённых моделей на локальной БД, конкурентные и вложенные запросы с разными моделями, production-сборка, интерфейс при ширине 1280 и 390 px.
