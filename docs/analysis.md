# Анализ референса 24contentzavod.ru

## Что это
Prepaid-SaaS: пользователь описывает бизнес → ИИ строит контент-план → генерирует пост/карусель/ролик → публикует. Сущности: **Завод** (конвейер под один продукт), **СММ-Центр** (ручное создание + публикации + входящие), **Студия** (разовые генерации), ИИ-агенты, «Лия» (чат-архитектор). Деньги списываются в момент генерации, при сбое возврат. Тарифы 0 / 4 990 / 9 990 / 14 990 / 29 990 ₽, лимит по числу заводов.

## Что в нём действительно хорошо (берём)
1. **Завод = один продукт.** Жёсткая граница не даёт смешивать темы — берём, но над ним ставим «бренд».
2. **Списание в момент сборки + автовозврат.** Прозрачно, нет страха «заплатил — не получил». Реализовано в `wallet.ts` (журнал + блокировка строки).
3. **Цена до нажатия кнопки.** Стоимость видна на кнопке. Берём везде.
4. **Режим одобрения идей** (идея → одобрена → генерация → готово) и автопубликация по расписанию.
5. **Онбординг-тур + подарочный баланс** — быстрый «первый результат».
6. **Лимит тарифа на число заводов** — понятная монетизация.

## Слабые места (исправляем)
| Слабость референса | Что делаем у себя |
|---|---|
| Нет уровня «клиент/бренд» над заводом: агентство с 20 клиентами получает 20 несвязанных заводов | **Организация → Бренды → Заводы.** Профиль бренда, тон и запреты один раз, у каждого бренда свои каналы. Переключатель организаций для агентств |
| Анкета завода — 7 шагов + 13 вкладок настроек (Продукт, Фото, Ссылка, Посты, Карусели, Стиль, Компания, Ограничения, Аватар, Субтитры, Хук, Соцсети, Автопубликация) | Один экран создания, остальное — умные значения по умолчанию, расширенные настройки позже |
| Платная генерация в основном видео/картинок: дорого, сбои, «зависшие генерации» (видно по changelog) | Текст-первый: дёшево, быстро, надёжно. Медиа подключаем провайдерами позже |
| Зарубежные соцсети закрыты paywall, нет VK/Telegram-first для РФ | VK, Telegram, Дзен, webhook на сайт — базовые каналы |
| Нет заметной защиты от повторов тем (план пересоздаётся «с нуля») | В промпт плана передаются уже использованные темы завода |
| Нет ролей/команды (клиент не может только согласовывать) | Роли owner/admin/editor/viewer в схеме с первого дня; клиентский логин «только согласование» — следующий этап |
| Нужен гид-бот «Лия», чтобы разобраться — признак сложного UX | Упрощаем сам UX вместо гида |
| Нет API/вебхуков кроме тарифа «Корпоративный» | API и webhook-публикация — часть модели каналов |

## Что интересно для будущего
- **Обучение на обратной связи** (v2 у них): сохранять правки пользователя к тексту и подмешивать как few-shot — у нас правки уже сохраняются в `content_items.body`.
- **Анализ конкурентов, тренды** — платная фича «Про».
- **Реферальная «Партнёрка» и «Вирус»** — готовый канал роста для платных клиентов.

## Архитектура
Multi-tenant на одной БД: каждая таблица несёт `org_id`, **единственный источник `org_id` — сессия** (`requireCtx`), все запросы фильтруют по нему. Неограниченное число компаний и заводов ограничивается только тарифом (`plans.ts`, `null` = безлимит). Открытые проекты для изучения: [Postiz](https://github.com/gitroomhq/postiz-app) (планировщик публикаций, 30+ соцсетей, NestJS+Next) — как референс адаптеров каналов, а не как основа (AGPL, свой стек Temporal/Redis).

## Что не сделано (честно)
- Реальная публикация в каналы (адаптеры Telegram/VK) и cron-воркер по расписанию.
- Платежи (ЮKassa) — смена тарифа закрыта флагом `ALLOW_FREE_PLAN_SWITCH`.
- Изображения/видео/аватары (Студия — заглушка).
- Приглашение участников, клиентский режим согласования, онбординг-тур.
